Решение по раскатке

1 Что проверяли

Гипотеза

Если снизить порог бесплатной доставки до 2 000 ₽, часть клиентов с дешёвыми корзинами, которым сейчас доставка обходится в 250 ₽, передумает уходить из корзины — конверсия сессии в заказ вырастет.

Проверяемая механика: бесплатная доставка перестаёт быть «наградой за крупный чек» и становится универсальной — эффект должен быть сильнее на малых корзинах, где 250 ₽ заметны.

      6 Решение и следующий шаг

      Данные синтетические. 300 000 сессий сгенерированы с фиксированным seed (np.random.default_rng(20261104)) по механике «эффект сильнее на малых корзинах». Все числа на странице вычислены из этих данных, а не вписаны руками.

      Стек: Python 3.11, numpy, scipy (двухвыборочный z-тест для долей, Welch t-test для средних, χ²-тест для SRM), рукописный SVG без внешних библиотек. Воспроизведение: python build.py → results.json, data/*.csv, эта страница.
