Что здесь честно, а что нет. Данные — публичный API DefiLlama, снимок на момент сборки; это не исторический ряд из первичных логов блокчейна. TVL протокола складывается по всем сетям, поэтому сумма по категориям не равна сумме по сетям: один протокол может сидеть в пяти сетях. В рейтинг протоколов попадают и централизованные биржи (Binance CEX, OKX, Bybit) — DefiLlama считает их TVL по резервам, и это заметная часть топ-10; если нужен только DeFi, эти строки надо отфильтровать по категории. Денежная масса стейблкоинов — только USD-pegged часть, евро и прочие валюты в эту цифру не входят.

Как это сделано. Снимок JSON → база SQLite → все цифры считаются SQL-запросами из queries/ → SVG-графики на чистом JS, без библиотек и CDN. Один и тот же SQL можно переписать под Dune, если понадобится считать по логам блокчейна, а не по агрегатору.

Чего пока нет. Адресных метрик (сколько уникальных кошельков в протоколе), потоков в разрезе отдельного дня и сравнения с прошлым годом по каждой сети. Это следующий шаг, а не забытое.
