# Дашборд продавца маркетплейса

Одностраничный BI-дашборд по продажам: выручка, заказы, средний чек, воронка,
ABC-анализ ассортимента, возвраты, когортное удержание и загрузка по часам.

**Задача, которую он решает.** Продавец видит цифры в личном кабинете
маркетплейса, но не видит связей: какие SKU дают 80% выручки, в какие часы
приходит трафик, на каком шаге теряются заказы, какие категории возвращают
чаще других. Дашборд собирает это в одну картину с фильтрами по периоду и
категории.

## Что внутри

| Блок | Что показывает | Зачем бизнесу |
|---|---|---|
| 6 KPI-карточек | выручка, заказы, средний чек, выкуп, возвраты, заказов в день | состояние бизнеса одним взглядом |
| Динамика | выручка и заказы по дням + скользящее среднее за 7 дней | отличать тренд от недельного шума |
| Воронка | показы → переходы → корзина → заказ → выкуп | где именно теряются деньги |
| Категории | вклад в выручку | на чём держится оборот |
| Топ-10 SKU | лидеры по выручке | что продвигать и чем не рисковать |
| ABC / Парето | накопленная доля выручки по SKU | сколько позиций реально зарабатывают |
| Возвраты | доля возвратов по категориям | где ломается качество или описание |
| Когорты | удержание помесячных когорт | возвращаются ли клиенты |
| Часы × дни | тепловая карта заказов | когда ставить акции и смены поддержки |

## Технически

- `build.py` — генерирует данные и вшивает их в шаблон.
- `template.html` — вёрстка и вся отрисовка: **чистый JS + SVG, без единой
  внешней библиотеки и без CDN**. Файл открывается офлайн двойным щелчком и
  работает в любом браузере.
- `dashboard.html` (120 КБ) — готовый дашборд.
- `data/*.csv` — те же данные, если нужно проверить расчёты.

```bash
PYTHONIOENCODING=utf-8 python build.py   # пересобрать dashboard.html
```

Экспорт в CSV встроен в интерфейс: любой график можно выгрузить и проверить
в Excel.

## Про данные — честно

Датасет **синтетический**. Структура повторяет реальный кейс продавца
(топ-100 на Wildberries): 180 дней, 8 категорий, 96 SKU, сезонность, распродажи,
возвраты по категориям. Значения сгенерированы, чтобы показать методологию и
дизайн, а не выдать чужие цифры за свои.

## Что проверено

Дашборд прогнан через Playwright: 0 ошибок в консоли, все 8 графиков
отрисовываются, фильтры по периоду и категории пересчитывают KPI. Проверка
лежит в `career-ops/output/verify-dashboard.mjs`, если понадобится повторить.
